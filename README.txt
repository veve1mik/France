КАК ОТКРЫТЬ САЙТ
1. Полностью распакуйте архив.
2. Откройте france_project/index.html в браузере.
3. Сохраняйте структуру папок: изображения и JS подключаются по относительным путям.
4. Интернет нужен только для внешних ссылок и отправки форм на httpbin.org.

СТРУКТУРА
index.html — главная.
architecture.html, culture.html, language.html, walk.html, gallery.html — информационные страницы.
forms.html — две формы.
passport.html — «DOM_JS. Считываем информацию из DOM».
passport_latin.html — «Изменяем кириллицу на латиницу по клику».
task.html — «Решение алгоритмической задачи» (задача 1009).
photo_*.html — крупные фотографии 600 × 400 для переходов по миниатюрам.
images — изображения. js — три файла JavaScript.

CSS НЕ ИСПОЛЬЗУЕТСЯ
В проекте нет файлов .css, тега style, атрибутов style и class.
Оформление сделано только HTML-атрибутами из семинаров и сайтов-примеров:
  bgcolor            — цвет фона ячейки таблицы (семинар 4 cardio, лекция 4);
  background         — картинка на фоне таблицы или ячейки (лекция 4);
  align / valign     — выравнивание по горизонтали / вертикали (лекции 3, 4);
  width / height     — ширина и высота ячеек и картинок (лекция 4);
  border, cellspacing, cellpadding, colspan, rowspan — рамка и отступы таблицы (лекция 4);
  <font color size face> — цвет, размер и шрифт текста (лекция 3, семинар 1);
  <hr color size>    — цветная линия (семинар 1, лекция 3);
  <ul type="square"> — вид маркеров вложенного списка (семинар 1, лекция 3);
  <b>, <i>, <sup>, <blockquote>, <pre>, <figure>, <figcaption> — из лекции 3 и семинара 3.

КАК ВЫПОЛНЕНЫ ТРЕБОВАНИЯ
1–5. Навигация — таблица вверху каждой страницы. Текстовые ссылки и картинка-ссылка на главную
     (домик) открываются в текущем окне. «Таблица памятников» — ссылка на закладку
     architecture.html#compare. «ЮНЕСКО» — внешний сайт в новом окне (target="_blank").
     Текущая страница выделена: ячейка закрашена bgcolor, текст жирный и белый (<b><font>).
6.   На каждой информационной странице — ссылки на разделы (#id) и «К началу» (#top).
7.   Нумерованные (ol), ненумерованные (ul) и вложенные списки — architecture.html, language.html.
8.   Фотографии с подписями — index, architecture, culture, walk.
9.   Миниатюры шириной 100 px открывают в новом окне страницы photo_*.html,
     где фото 600 × 400 стоит по центру (<p align="center">).
10.  architecture.html#compare — таблица с background, картинкой в ячейке и ссылками.
11–12. forms.html — контактная карточка и тематическая форма (text, number, radio, checkbox,
     date, password, hidden, значения по умолчанию). Отправка на httpbin.org методом POST.
13–14. Паспорт — таблица с фоном-бланком (как в задании лекции 4 «паспорт таблицами»):
     высоты строк и ширины пустых ячеек подобраны по линиям бланка; сумма высот = 620 px.
     Задача 1009 — task.html.

КАК ОБЪЯСНИТЬ КОД
<a href="culture.html"> — ссылка на соседний HTML-файл.
<a href="#arts"> — ссылка на элемент id="arts" в текущем файле; <a id="top"></a> — закладка.
<a href="architecture.html#compare"> — ссылка на фрагмент другой страницы.
target="_blank" — открыть ссылку или ответ формы в новой вкладке.
<img src="images/bridge.jpg" width="100"> — картинка из папки images шириной 100 пикселей.
id — уникальное имя элемента, по нему JavaScript находит элемент.
form action — адрес сервера; method="post" — отправка данных в теле запроса.
name у поля — имя переменной, которую получает сервер.
value / checked — значения по умолчанию.

JavaScript (только приёмы из семинаров 2, 5, 6):
getElementById — найти элемент по id.
innerText — прочитать или поменять текст элемента.
value — прочитать или поменять значение поля формы.
parseFloat — преобразовать текст в вещественное число; isNaN — проверка «не число».
addEventListener("click", функция) — вызвать функцию при клике.
if / else if / else — выбор действия по условию; || — «или», && — «и».
document.getElementById("UserEnter").submit() — отправить форму, если check = true.
alert — сообщение об ошибке; console.log — вывод в консоль.
